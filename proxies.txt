# Proxy Format Examples
# ======================
# This file supports multiple proxy formats:
#
# Format 1: Simple host:port
# 192.168.1.1:8080
#
# Format 2: With protocol
# http://192.168.1.1:8080
# https://192.168.1.1:8080
#
# Format 3: With authentication (username:password@host:port)
# user:pass@192.168.1.1:8080
#
# Format 4: With protocol and authentication
# http://user:pass@192.168.1.1:8080
# https://user:pass@192.168.1.1:8080
#
# Format 5: Colon-separated (username:password:host:port)
# user:pass:192.168.1.1:8080
#
# Format 6: Alternative colon-separated (host:port:username:password)
# 192.168.1.1:8080:user:pass
#
